api key genration : 

An API key is like a password for your application that allows it to access someone else’s service (like OMDb API, OpenWeather, Google Maps, etc.).

When we say “generate an API key”, it means you are registering with the API provider so they can:

Identify your app or account – they know which requests come from you.

Control usage – they can limit how many requests you can make (rate limiting).

Secure the service – only authorized users with valid keys can access the data.




---------------------------------------------------------------------------------------------------------------------------------------------------------


fetch(url)

Sends a request to the server at the given url.

Example:

fetch(`https://www.omdbapi.com/?apikey=YOUR_KEY&s=avengers`)


This asks OMDb: “Give me movies that match ‘Avengers’.”

.then(response => response.json())

The server responds with raw data.

.json() converts it into a JavaScript object so you can use it.

.then(data => ...)

Now data contains the movie info from OMDb.

You can loop through it, extract titles, posters, year, etc., and show them on the page.

.catch(error => ...)

If something goes wrong (like no internet or wrong API key), this handles the error.
